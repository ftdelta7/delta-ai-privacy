Privacy Policy for Delta

Last updated: [25-05-2026]

This Privacy Policy explains how Delta (“the bot”, “we”, “our”, or “us”) collects, uses, stores, and protects information when you use Delta in Discord servers.

By using Delta, you agree to this Privacy Policy.

1. Information We Collect

Delta may collect and process the following information:

* Discord user IDs
* Discord server IDs
* Discord channel IDs
* Command usage data
* Bot configuration settings
* Music queue and playback-related data
* Messages sent directly to Delta
* Messages where Delta is mentioned
* Messages in configured AI/study channels, if the server has enabled AI features
* Error logs and diagnostic information needed to keep the bot working

Delta does not collect message content from every server channel by default. Message content is only processed when it is needed for bot features, such as AI assistant responses, direct interactions, mentions, or configured channels.

2. How We Use Information

Delta uses collected information to:

* Respond to user commands
* Provide AI study assistant responses
* Answer natural-language questions from students and server members
* Manage music playback, queues, and playlists
* Save server-specific settings
* Prevent abuse and spam
* Debug errors and improve bot reliability
* Keep the bot secure and functional

Delta does not sell user data. Delta does not use message content for advertising, profiling, or unrelated tracking.

3. AI Features

Delta includes AI assistant features that allow users to ask questions, request explanations, summarize information, and ask follow-up doubts.

When a user interacts with the AI feature, the relevant message content may be processed to generate a response. This may include the user’s question and limited conversation context needed to provide a useful answer.

Server admins may restrict AI features to specific channels where supported.

4. Music Features

Delta includes music features such as playing songs, managing queues, skipping tracks, pausing playback, and playlist features.

For music features, Delta may process song names, search queries, queue data, voice channel IDs, and related playback information.

5. Data Storage

Delta may store limited data needed for operation, including server settings, user preferences, playlists, command logs, and diagnostic logs.

Message content used for AI responses is only stored if necessary for functionality, debugging, abuse prevention, or conversation context. We aim to keep stored data limited and only for as long as needed.

6. Data Sharing

Delta may share limited data with third-party services only when required to provide bot features. For example:

* AI service providers may process user questions to generate AI responses.
* Music/search providers may process song searches or media requests.
* Hosting and database providers may store bot configuration and operational data.

We do not sell or rent user data to third parties.

7. User and Server Admin Controls

Server administrators can remove Delta from their server at any time.

Where supported, server administrators can configure or disable specific features, including AI-related features.

Users may avoid using AI features by not sending questions to Delta, not mentioning Delta for AI help, and not using configured AI channels.

8. Data Removal Requests

Users or server administrators may request deletion of stored data related to their server or account by contacting us.

Contact: deltadevofficial@gmail.com

Please include relevant information such as your Discord user ID or server ID so we can locate the data.

9. Security

We take reasonable steps to protect stored data from unauthorized access, misuse, or loss. However, no online service can guarantee complete security.

10. Children’s Privacy

Delta is intended for use on Discord and follows Discord’s Terms of Service. Users must meet Discord’s minimum age requirements to use the platform.

11. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be posted at the same location where this policy is hosted. Continued use of Delta after changes means you accept the updated policy.
